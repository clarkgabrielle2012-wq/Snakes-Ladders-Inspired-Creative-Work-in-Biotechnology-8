📘 BioLab Quest Rules & Mechanics

🎯 Objective Race from Tile 1 (Lab Entry) to Tile 50 ( Nobel Discovery) by rolling the dice and mastering laboratory science questions.
🧬 DNA Double-Helix Ladders (Boosts) Land on the base of a DNA Helix (e.g., Tile 4 → 16, Tile 12 → 28). Answer the question correctly to climb the DNA strand! If you miss, you stay at the base.
☣️ Biohazard & Chemical Spill Chutes Land on a Biohazard Spill top (e.g., Tile 19 → 6, Tile 47 → 30) and you must answer a General Lab Safety question to neutralize the hazard! Answer right to stay safe; answer wrong (or lack a Safety Shield 🛡️) and you slide down!
🔬 Standard & Apparatus Stations Every turn tests your knowledge! Answering standard tile questions correctly grants +100 Research Points and charges a Safety Shield 🛡️ (every 3 streak answers).

🚀 Host on GitHub Pages in 60 Seconds

This entire game is self-contained in a single index.html file with zero external audio/image dependencies, making it ready for GitHub Pages.

  1. Create a new public repository on GitHub.com (e.g., biolab-quest).
  2. Save this code as index.html and upload/commit it to the main branch.
  3. Go to your repository Settings → Pages.
  4. Under Build and deployment, select Deploy from a branch → main → / (root) and click Save.
  5. Your playable game URL (https://username.github.io/biolab-quest/) goes live automatically!
